# Proposal: bootstrap-foundation

## Why

`sentinel-pro` is still a raw Next.js starter. If implementation begins now, the project will drift immediately because there is no SDD persistence, no TDD tooling, and no local architecture source of truth beyond the chat.

## What Changes

- initialize OpenSpec for this repository
- define the bootstrap architecture/testing spec
- configure Vitest + Testing Library + coverage
- replace the starter homepage with a project foundation page

## Impact

- contributors can start real changes with SDD artifacts instead of improvisation
- tests become available before the first domain feature
- the repository reflects the intended Sentinel Pro direction from day one
